## ۵. چک‌لیست دستی smoke (برای production کاربر)

1. `MONGODB_URI=… python3 tools/health/data_health.py` → گزارش سلامت (exit 0 = سالم).
2. مینی‌اپ → یادگیری → تمرین یک درس تا اتمام → کارت «ساخت سؤال هوشمند» → پاسخ → «پیشنهاد به بانک» → در پنل Questions وضعیت pending ظاهر شود.
3. پنل Subscriptions → تب همه → وضعیت‌های cancelled/refunded با برچسب فارسی.
4. پنل Users → suspend/unsuspend کاربر آزمایشی → ربات و مینی‌اپ دسترسی را قطع/وصل ببینند (≤۳۰s).
5. `python3 tools/audit2/m0*_*.py` (۴ اسکریپت) → خروجی تازه در docs/audit2-data/.
6. سوئیت: `python3 -m pytest tests/ -q` → باید همان شکست‌های محیطی قبل باشد (هیچ فایل مرتبط با این تغییرات نباید fail شود) + `tests/test_data_contract.py` کامل سبز.
