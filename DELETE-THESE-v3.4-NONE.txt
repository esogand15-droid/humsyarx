نکات مهم این دور:
 • `/` دیگر ۳۰۷ به /app/ نیست؛ HTML واقعی لندینگ سرو می‌شود.
   اگر بیلد لندینگ نباشد، همان ۳۰۷ قبلی برمی‌گردد (بدون شکستن دیپلوی).
 • باگ واقعی: فونت‌های خودمیزبان روی `/fonts/...` در production ۴۰۴
   می‌شدند؛ حالا /fonts و /icons از miniapp/public سرو می‌شوند.
 • بیلد سوم: `npm run build:landing` → miniapp/dist-landing (Dockerfile
   هم آن را می‌سازد و self-check دارد).

مراحل امن:
  ۱) ZIP را در ریشهٔ ریپو extract کنید.
  ۲) git status → باید فقط ۱۵ مسیر را ببینید.
  ۳) commit + push روی همان برنچ Railway.
  ۴) Railway بیلد می‌کند؛ بعد: https://<domain>/ باید لندینگ بدهد و
     https://<domain>/api/health باید "landing": true داشته باشد.
