هامزیار — کلاینت وب دانشجو (P0)  ·  نسخهٔ 0.1.0
==================================================

این پوشه (apps/student) را در ریشهٔ مخزن هامزیار بگذارید:

    humsyarx/
    ├── api/  bot.py  db/  miniapp/  webadmin/
    ├── apps/
    │   └── student/          ← همین پوشه
    └── delivery/CHANGELOG.md ← اختیاری

هیچ فایلی از ربات، API، مینی‌اپ یا پنل ادمین تغییر نکرده است.

اجرا روی سیستم خودتان
---------------------
    cd apps/student
    npm install
    npm run dev

آدرس پیش‌فرض:  http://localhost:5173/app/
(اپ عمداً زیر /app/ بیلد می‌شود تا بعداً روی همان دامنهٔ هامزیار در /app سرو شود)

ساخت نسخهٔ نهایی
----------------
    npm run build
خروجی در apps/student/dist/ ساخته می‌شود.

مهم برای استقرار: اپ زیر مسیر /app می‌بیلد می‌شود، پس وب‌سرور باید
مسیرهای /app/* را به /app/index.html برگرداند (SPA fallback).
مثال Caddy:
    handle_path /app/* {
        root * /srv/humsyar/app
        try_files {path} /index.html
        file_server
    }
